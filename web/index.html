Try fingerprint identification in your browser

This page runs the real AFIS engine (the same Python code as the desktop app) on synthetic fingerprints that belong to no one. Four demo people are enrolled from one print each; pick another print and see whether AFIS finds the right person.

  • Private by design. Everything runs on your device. There is no upload, and the demo database is held in memory and discarded when you close the tab.
  • Synthetic prints only. The demo does not accept real fingerprints.
  • Probabilistic. Scores are evidence, not proof of identity. AFIS is educational and has not been validated for forensic or law-enforcement use. The demo prints are curated to be easy; on real scans the error rate is much higher (see the accuracy notes).
